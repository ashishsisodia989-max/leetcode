# 1. Two Sum

## Problem

https://leetcode.com/problems/two-sum/

## Approach

Use a HashMap.

Store each value and its index.

For every element:

Check if target-current exists.

If yes, return indices.

Else insert into HashMap.

---

## Complexity

Time : O(n)

Space : O(n)
